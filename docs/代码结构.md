# 底盘代码结构

现在按职责拆成四个应用模块。`main.c` 只保留外设初始化、中断回调和时钟配置。

| 文件 | 负责什么 | 不负责什么 |
|---|---|---|
| `Core/Src/main.c` | HAL 初始化、CAN/UART/TIM 回调、时钟配置 | 底盘运动计算、速度 PI、SBUS 解码 |
| `Core/Src/chassis_app.c` | 1 ms 调度、遥控归一化、SC 档位、云台反馈存储、LED 状态 | HAL 外设初始化 |
| `Core/Src/chassis_control.c` | 手动/自旋/跟随模式、云台角度坐标变换、四轮目标转速分配 | 硬件、CAN 收发和速度 PI |
| `Core/Src/chassis_motor.c` | 四轮速度 PI、电流输出、0x200 发送、0x201~0x204 反馈解析 | 摇杆解析和底盘运动模式 |
| `Core/Src/rc_sbus.c` | 25 字节 SBUS 帧拼接、16 通道解码、failsafe 和时间戳 | 通道用途解释和底盘模式 |

## 数据流

```text
USART1 中断
  -> RC_SBUS_ReadByte()
  -> rc_sbus.c 拼帧并更新 rc_ch[]
  -> ChassisApp_Run1ms()
  -> RC_SBUS_CopyData()
  -> App_ScaleStick() 读取摇杆
  -> SC 三档转换成 ChassisSpinMode
  -> ChassisControl_Step()
  -> ChassisControl_Mix()
  -> ChassisMotor_Update()
  -> 速度 PI、四路电流、CAN 0x200
```

CAN1 接收方向：

```text
CAN1 0x201~0x204 中断
  -> ChassisMotor_ReadCAN()
  -> 更新 motor[0..3].rpm
  -> ChassisMotor_Update() 读取转速做速度 PI
```

## 调试变量

- `rc_ch[0..5]`：SBUS 原始通道值，在 `rc_sbus.c`。
- `rc_mode`：当前自旋档位，在 `chassis_app.c`。
- `chassis_command`：当前 vx/vy/wz 和模式，在 `chassis_app.c`。
- `motor[0..3]`：转速、目标、误差、积分和电流，在 `chassis_motor.c`。
- `ChassisApp_SetGimbalFeedback()`：云台反馈入口，实现在 `chassis_app.c`。

## 编译

```powershell
cmake --build build/Debug
```
