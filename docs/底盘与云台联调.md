# 底盘与云台联调

当前工程完成底盘侧的模式、云台反馈接入点、云台系到底盘系变换和轮速混合。
默认不安装云台，可以先验证底盘。尚未烧录或进行实车测试。

## 1. 先区分两种角度

- 云台相对底盘的角度：供底盘跟随和坐标变换使用，通常来自 Yaw 轴编码器减去安装零位。
- 云台相对地面的朝向：供云台保持瞄准方向使用，由云台 IMU 姿态、陀螺仪和云台电机闭环处理。

小陀螺时，底盘旋转，云台电机需要主动反向补偿才能保持对地朝向。
锁住云台相对底盘的机械角度，会让云台跟着底盘转。底盘代码本身无法让云台对地保持朝向。

无云台时没有真实的云台坐标系。当前采用车头坐标驾驶，不再积分期望自旋速度去猜角度。
将来如果还需要在无云台时实现对地定向平移，需要另外接入底盘实际航向反馈。

## 3. 当前操作方式

`Core/Inc/chassis_control.h` 中保持：

```c
#define CHASSIS_GIMBAL_INSTALLED 0U
```

SD 仍是总使能。SC 档位沿用本次修改前工作区里的两档自旋安排：

| SC | 没有云台，配置为 0 | 装好云台并接通反馈，配置为 1 |
| --- | --- | --- |
| 下档，约 1695 | 手动模式：按车头平移，`rc_ch[0]` 控制转向 | 底盘跟随云台，平移按云台朝向 |
| 中档，约 1024 | 低速自旋，平移按车头朝向 | 低速自旋，平移按云台朝向 |
| 上档，约 353 | 高速自旋，平移按车头朝向 | 高速自旋，平移按云台朝向 |

开启自旋后，转向摇杆不叠加到固定自旋指令。
无云台配置下，旋转时一直推前，移动方向也会随车头转动，这是当前选择的控制方式。
有云台配置下，普通模式的转向摇杆应交给未来的云台控制，底盘不再直接使用它。
当前工程还没有云台目标角生成或云台驱动，这部分需要装云台时完成。

参数集中在 `chassis_control.h`：

- 低/高速自旋分量：1500 / 3000 转子 rpm。
- 无云台手动转向上限：1500 转子 rpm。
- 跟随：比例环、有死区和输出限幅；现有默认值只用于后续调试起点。
- 这些 rpm 是轮速分量，不是底盘角速度；没有底盘角速度闭环。

四轮混合超过 `ROTOR_RPM_LIMIT` 时共同缩小，保留平移与旋转的合成比例。
因此大幅平移时，自旋分量也可能下降；实际地面转速还受打滑和负载影响。
若以后要求平移时优先保持自旋速度，需要增加旋转优先的轮速分配策略。

原工作区里的平移上限 8000 rpm、轮速上限 8000 rpm、速度 PI 和电流输出上限 6000 raw 保持原值。

## 4. 现在按这个顺序调试

1. 保持无云台配置。先架空、低幅度给杆，核对四轮反馈、正负号、前进、横移和手动转向。
2. 分别测试 SC 下/中/上档，先低速原地自旋，再低速平移叠加自旋，确认切档和 SD 失能行为。
3. 检查关闭遥控器、拔掉接收机信号等情况：`rc_lost` 应变为 1，四路 `motor[].cmd` 为 0，积分清零。
4. 电脑上运行 `tests/run_chassis_tests.cmd`，先验证虚拟角度的跟随和坐标变换，无需虚拟角度驱动实车。
5. 上车观察负载下的速度误差、电流和振动，再决定是否调整原有速度 PI、增加指令斜坡。

Watch 建议观察：`rc_ch[0..5]`、`rc_mode`、`rc_enable`、`rc_lost`、
`chassis_command`、`motor[0..3].rpm/target/integ/cmd`。

## 5. 装云台时如何接入

先确定单板或双板、电机型号、编码器分辨率与减速比、通信总线，然后实现实际反馈解析。
当前没有预设通信 CAN ID，也没有把现有 `0x201~0x204` 的底盘电机帧当作云台帧。

接口声明在 `chassis_app.h`，实现在 `chassis_app.c`：

```c
/* 仅在新收到一帧有效的实际反馈后调用。 */
ChassisApp_SetGimbalFeedback(relative_yaw_rad);
```

角度约定：云台朝向减去底盘朝向，云台与车头对齐为 0，俯视逆时针为正。
如果编码器正方向相反，在反馈解析端取反。如果编码器在减速器电机端，必须先换算到云台输出轴。
控制计算内部会处理回绕；应传入安装零位标定后的角度。

```c
/* 示例公式：参数必须根据实际 Yaw 编码器确定，不是现有的接收代码。 */
relative_yaw_rad = direction * (encoder_count - align_count)
                   * radians_per_count_at_yaw_axis;
```

测试云台相对底盘向左 90°，输入应约为 `+1.5708f`。
此时底盘“跟随”输出应向左，云台“向前”的平移命令应变为底盘“向左”。
测试右侧 90° 时符号相反。先核对方向，再逐步调跟随增益。

只有完成真实反馈、方向和零位检查后，才把 `CHASSIS_GIMBAL_INSTALLED` 改为 `1U` 并重编译。
该配置下，云台反馈未收到、无效或超过 100 ms 未更新，底盘输出零电流并清积分；自旋模式同样如此。
不要在主循环重复喂上一次角度，否则会掩盖通信断线。

云台侧另外完成 IMU 姿态/角速度闭环。保持瞄准方向时使用稳定的对地目标角；
底盘自旋不应被直接累加到云台的对地目标角。

## 6. 比赛整车后续工作

当前工程只保留底盘运动控制和小陀螺逻辑，不包含总功率限制和超级电容扩功率控制。
云台控制和双板通信仍需后续完成。
